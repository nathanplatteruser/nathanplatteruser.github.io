A stack night

Camera. Beep. Files. Upload.

  • 1. Camera on. Laptop webcam or phone. Grocery-gun ISBN bursts still work if the gun is plugged in.
  • 2. Stack or Single. Stack = a pile. Single = one book. Kids tap the giant button.
  • 3. Beep per ISBN. Two-tone POS beep. No typing the number.
  • 4. Done, then grade. Very Good is the default. Excellent / Good / Poor are taps, not a form.
  • 5. Hydrate. Title, author, description, unique ISBN tag. Progress bar so nobody wonders if it froze.
  • 6. Keep floor (optional). “I want to keep $X.XX per book.” Reverse-engineered after Amazon referral + close, or eBay FVF, plus mailer and stamp.
  • 7. Take the files. eBay File Exchange CSV and Amazon Inventory Loader. Click to eBay Upload opens Seller Hub Reports.
  • 8. Listed ≠ sold. The sheet is an offer. The jar waits for a buyer.

Three speeds

Hands · File · Wire

Keys and APIs are optional. The File path is first-class so a homestead can list tonight.

Hands

Skip the sheet

Sort the three bins. Practice spines. Count the stamp. No marketplace, no CSV. Still a real shop lesson.

File · tonight

CSV / TSV without keys

Scan → hydrate → download. Upload in eBay Seller Hub Reports and Amazon Seller Central listing upload. Assumed logged in. Nothing publishes until they do.

Wire · later

Connect when you have keys

Amazon SP-API and eBay Inventory API sit behind Connect. Same pile. Same keep math. Wire is not required to finish a night.

Honest weakness: The GitHub Pages family copy is shop / story / jar in the browser. Camera stack, ISBN comps, keep reverse-engineer, and file builders run in the full Shelfmark desk. Source is public; the live desk is the working copy.

What this is not

vs clicking eBay

No twenty-form night

We do not grab a browser and fill listing forms one by one. We hydrate a pile and hand you a sheet.

vs generic $4.99

Unique ISBN tags

Comps are prompted per ISBN. Generic 4.99 / 5.99 / 8.99 / 9.99 tags get rejected unless that book really sells there.

vs “we sold it”

Listed is an offer

The jar counts keep after a sale. Uploading a CSV is not cash in the coffee can.
