# Shelfmark — family copy

Shop, story, and jar for the homestead kids. No typing. Count the stamp.

First visit gets a click-along: a short popup, then bubbles on the real buttons. If this browser has already sorted a book or finished the walk-through, the popup stays quiet.

The live desk (inventory, Amazon Inventory Loader, reel) is the full Shelfmark app. This folder is the GitHub Pages copy so the family can open it without a local server.
